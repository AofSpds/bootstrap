# 처음 시작하는 순서

1. 검토 대상 ZIP을 내려받고 **모두 압축 풀기**를 누릅니다. ZIP 창 안에서 실행하지 않습니다.
2. `bootstrap.bat`을 더블클릭합니다. 전체 스크립트를 무조건 관리자 권한으로 실행하지 않습니다.
3. AI는 기존 계정에 맞춰 선택합니다. ChatGPT는 Codex, Claude는 Claude를 고릅니다. 모르겠으면 0(None)으로 설치만 진행할 수 있습니다.
4. Python/JDK/Docker/DBeaver는 지금 필요하지 않으면 Enter로 건너뜁니다. Core 8종은 표시된 목록 그대로입니다.
5. 설치 예정 목록과 소프트웨어 약관을 검토하고 동의하면 `y`를 입력합니다. 취소하면 아무것도 설치하지 않습니다. 설치기가 관리자 권한을 요청하면 프로그램 이름을 확인하고 본인이 승인합니다.
6. `PRESENT_COMPATIBLE`은 이미 있어서 유지, `INSTALLED`는 설치 후 확인 완료, `ACTION_REQUIRED`는 수동 조치 필요, `FAILED`는 실패입니다. 실패한 부분만 확인하고 재실행할 수 있습니다.
7. GitHub Desktop 로그인 → 자기 프로젝트 Clone → Open in Visual Studio Code → AI 계정 로그인으로 이어갑니다.

설치할 때마다 프로그램을 업그레이드하지 않습니다. 프로그램 버전이 오래됐으면 개발자와 상의하여 본인이 업데이트한 뒤 다시 검사합니다. Node 설치에는 npm/npx가 포함됩니다.

계정 가입·비밀번호·OAuth 동의·유료 결제는 이 프로그램이 대신하지 않습니다. API 키를 대화창이나 GitHub에 올리지 않습니다. Windows 관리 정책 때문에 실행이 막히면 보안 설정을 해제하지 말고 관리자에게 문의합니다.

`bootstrap.bat`의 `-ExecutionPolicy Bypass`는 이 로컬 스크립트를 실행하는 프로세스에만 적용됩니다. 그룹 정책을 무시할 수 없으며 PC의 영구 실행정책은 바꾸지 않습니다. 서명된 정식 배포물인 것처럼 표시하지 않습니다.
