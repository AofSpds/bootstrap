# 문제 해결

| 표시/상황 | 할 일 |
|---|---|
| WinGet missing | Microsoft Store의 Microsoft App Installer를 설치/업데이트합니다. 임의 사이트의 WinGet 설치기를 쓰지 않습니다. |
| 공식 source 확인 실패 | `winget source list --name winget`를 확인해 개발자에게 알려주세요. 이 도구는 source를 자동 초기화하지 않습니다. |
| UAC를 취소함 | 취소는 정상적인 사용자 선택입니다. 필요한 권한이 있을 때 다시 Install을 실행합니다. |
| 기존 Node가 오래되었음 | 기존 설치를 자동 제거하지 않습니다. Node LTS 설치를 수동으로 정리한 뒤 Verify합니다. |
| 등록은 있는데 실행파일이 없음 | 사용자/시스템 설치 위치나 손상된 PATH를 개발자가 확인합니다. 다른 설치를 덮어쓰지 않습니다. |
| Node는 있는데 npm/npx 오류 | 터미널을 다시 열고 Verify합니다. 해결되지 않으면 Node 설치 복구가 필요합니다. |
| Docker prerequisite | WSL/가상화와 라이선스 조건을 먼저 확인합니다. 이 도구는 Windows 기능을 켜지 않습니다. Docker 없이 계속 개발할 수 있습니다. |
| AI 확장 실패 | VS Code를 한 번 연 뒤 공식 확장 이름과 publisher를 확인합니다. 추가 구독을 자동 결제하지 않습니다. |
| 설치 후 명령을 못 찾음 | 새 터미널에서 Verify. 재부팅이 필요하다는 표시가 있을 때만 작업을 저장하고 직접 재부팅합니다. |
| 회사/ARM64/Windows 10 PC | v0.1 검증 대상 밖입니다. 지원한다고 가정하지 않습니다. |

보고할 때 결과 표, 종료코드, 실패한 패키지 이름만 먼저 전달합니다. WinGet 원본 로그, 개인 경로, 계정 토큰, 화면의 비밀번호는 공개 이슈에 올리지 않습니다. Install의 정제 로그도 내용을 확인한 뒤 공유합니다.
